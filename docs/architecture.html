Key Composables

useFilters.js
Global Filter State
Singleton — shared across all views. Reactive refs for period, location, category, status.
useI18n.js
Internationalisation
EN/JA toggle. Auto-maps currency: USD or JPY (1:150 rate). Persisted in localStorage.
useAuth.js
Auth State
Current user, tasks array, logout, getInitials(). Bilingual user data.

Backend

main.py
FastAPI Application
All routes, CORS, Pydantic response models, filtering helpers
apply_filters() filter_by_month() Quarter mapping Q1–Q4
mock_data.py
In-Memory Data Store
Loads all JSON files at startup into Python dicts. No persistence — changes lost on restart.
7 data files Thread-safe dict Loaded once

Pydantic Models

InventoryItem
id, sku, name, category, warehouse, quantity_on_hand, reorder_point, unit_cost, location, last_updated
Order
id, order_number, customer, items[], status, order_date, expected_delivery, total_value, warehouse
DemandForecast
id, item_sku, item_name, current_demand, forecasted_demand, trend, period
BacklogItem
id, order_id, item_sku, quantity_needed, quantity_available, days_delayed, priority, has_purchase_order
PurchaseOrder
id, backlog_item_id, supplier_name, quantity, unit_cost, expected_delivery_date, status
SpendingSummary
total_procurement_cost, total_operational_cost, total_labor_cost, total_overhead (+ % changes)

Data Layer

inventory.json
Stock Levels
40+ items across 3 warehouses (SF, London, Tokyo). Categories: Circuit Boards, Sensors, Actuators, Controllers, Power Supplies.
orders.json
Customer Orders
80+ orders spanning Jan–Dec 2025. Statuses: Delivered, Shipped, Processing, Backordered.
demand_forecasts.json
Demand Forecasts
15+ items with trend direction (increasing / stable / decreasing) for next 30-day period.
backlog_items.json
Inventory Shortages
Small demo set (3–5 items). Priority: high / medium / low. References order and inventory SKUs.
spending.json
Financial Data
Monthly procurement, operational, labor, overhead costs Jan–Dec. Category breakdowns.
purchase_orders.json
Purchase Orders
Starts empty. Populated at runtime via POST /api/purchase-orders. Not persisted across restarts.
